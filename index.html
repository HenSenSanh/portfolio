License Plate Recognition (ALPR) System

Collaborative & Academic Project • NHTung-0801/license_plate_recognition
2025 – Present
Problem:

Extracting characters from license plates in unconstrained environments is challenging due to illumination variances and complex layouts (e.g., 1-line vs. 2-line Vietnamese plates), which severely degrade the segmentation and accuracy of generic OCR models.

Solution & Pipeline:
  • Engineered a 5-stage traditional Computer Vision and Machine Learning pipeline. Deployed YOLOv8 for precise plate localization and ROI cropping.
  • Built a robust OpenCV preprocessing module (angle correction, CLAHE, adaptive thresholding, morphology) and applied Connected Components to dynamically segment and sort characters by layout.
  • Extracted HOG (Histogram of Oriented Gradients) features to train a Support Vector Machine (SVM) classifier instead of heavy deep learning OCR, paired with rule-based post-processing to decode and validate Vietnamese province codes.
Result:

Delivered a highly interpretable, end-to-end ALPR system. The HOG + SVM architecture combined with strict syntax validation achieved reliable accuracy on Vietnamese plates, while systematic confidence and raw string logging enabled continuous error analysis and model refinement.
